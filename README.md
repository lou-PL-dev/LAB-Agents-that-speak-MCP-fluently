# Agents that speak MCP fluently

A small LangChain agent that answers questions about the EU AI Act and a
podcast on the EU HLEG Ethics Guidelines for Trustworthy AI, using an MCP server 
for retrieval instead of raw file access.

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

Make sure `.env` contains:
```
OPENAI_API_KEY=your-key-here
```

## Run

```bash
# 1. Generate chunks.jsonl from the source documents (already included,
#    but re-run this if you change the input files)
python3 data_prep.py

# 2. Run the agent (this spawns mcp_server.py automatically as a subprocess)
python3 mcp_langchain.py
```

You can also run the MCP server standalone to inspect its tools:
```bash
python3 mcp_server.py
```

Running `mcp_langchain.py` also saves the agent's internal graph (model
node <-> tools node loop) to `agent_graph.mmd` (Mermaid source - paste
into https://mermaid.live to view) and `agent_graph.png` if your machine
can reach the rendering service.

## Files

| File | Purpose |
|---|---|
| `lab_config.py` | Paths, chunking, and source-label constants |
| `data_prep.py` | PDF/text extraction + chunking + legal-structure tagging |
| `mcp_server.py` | MCP server exposing search/list/get tools over the chunks |
| `mcp_langchain.py` | LangChain/LangGraph agent connected to the MCP server |
| `chunks.jsonl` | Generated by `data_prep.py` |
| `lab_proof.md` | Deliverable: query, evidence, answer, limitation |
